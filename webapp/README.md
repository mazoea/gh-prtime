# GitHub PR Time ETA Dashboard

Web interface for monitoring PR/Issue ETA tables.

## Quick Start

```bash
# Run the dashboard
start.bat
```

Visit http://localhost:5000

## Files

- `web_app.py` - Flask backend
- `templates/dashboard.html` - Frontend UI
- `requirements.txt` - Python dependencies
- `start.bat` - Startup script

## Configuration

Uses `../settings.json` from parent directory. Default max_items: 200.
